FILE DEL PROGRAMMA (cartella Desktop\mod italiano\CotW Italiano)
- CotW_Italiano.py ........ avvio (errori senza console -> %APPDATA%\CotW Italiano\errori.log)
- cotw\__init__.py ......... VERSIONE
- cotw\core\percorsi.py .... trova gioco (Steam/librerie/Epic), dropzone, salvataggi (Documenti\Avalanche Studios\COTW\Saves\<n>), dati app, gioco aperto?
- cotw\core\archivi.py ..... hashlittle + lettura (sola) degli archivi game*.tab/.arc
- cotw\core\installa.py .... componenti testo/audio: installa, rimuovi, stato, attiva/disattiva (dropzone <-> dropzone_off)
- cotw\core\quad.py ........ volume quad (banco vehicles.fmod_bankc dagli archivi -> dropzone), volume attuale, ripristina
- cotw\core\missioni.py .... backup con nome (_nome.txt, _origine.txt), elenco, rinomina, elimina, azzera, ripristina
- cotw\core\avvio.py ....... opzioni di avvio: lettore/scrittore VDF di Steam (userdata\*\config\localconfig.vdf,
                             apps\518790\LaunchOptions, backup in %APPDATA%\CotW Italiano\backup_steam), collegamento .lnk
- cotw\core\rete.py ....... indirizzi GitHub/Discord/Ko-fi, lettura versione.json, scaricamento con controllo SHA-256
- cotw\core\aggiornamenti.py cache scaricati, scelta pacchetti (piccolo o base+agg.), riuso dalla dropzone, confronto
- cotw\core\segnala.py ..... ricerca battuta (senza accenti, tutte le parole), messaggio pronto per Discord
- cotw\ui\finestra.py ...... 7 schede (Home, Installa, Avvio gioco, Salvataggi, Strumenti, Segnala errore,
                             Impostazioni); lavori lunghi in QThread con barra; controllo online all'avvio
- strumenti\pubblica.py .... (solo autore) crea pacchetti + Release su GitHub; --prova non carica niente
- strumenti\PUBBLICA_AGGIORNAMENTO.bat  menu prova / pubblica
- cotw\ui\stile.py ......... tema scuro, accento verde
- risorse\missions_missiondata_adf  file delle missioni azzerate;  risorse\spunta.svg (spunta caselle)
- .gitignore ............... esclude .venv, token, chiavi, _pubblica
